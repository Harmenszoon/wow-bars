# Harmenszoon's Bars

Customize Blizzard's action bars, bag bar, micro menu, and HUD in WoW Forever. Open **Edit Mode**, select the element you want to change, then save your layout.

- **Action bars and pet bar.** Reduce **Icon Padding** to 0 or 1, choose clipped or square icons, or add a thin outline.
- **Idle Opacity.** Set how visible a bar is at rest. It returns to its normal opacity as soon as you hover over it.
- **Bag bar and micro menu.** Adjust the size from 25% to 300% and hide the background independently.
- **Hide in Gameplay.** Hide an element such as the Objective Tracker during play. Open Edit Mode to select it again.

## Installation

In WowUp, select **Get Addons**, then **Install from URL**, and paste this repository's address. [Repository URL](https://github.com/Harmenszoon/wow-bars)

For manual installation, extract the `-forever.zip` release asset into `_forever_/Interface/AddOns/` so it contains `Bars/Bars.toc`. [Download the latest release](https://github.com/Harmenszoon/wow-bars/releases/latest)
